# zyphonOS.github.io

Public website for the ZyphonOS ecosystem, served by GitHub Pages from main at the repository root.

## What this site is

A shared entrance for four independent participants. It is not a corporate group site, and the participants are not subsidiaries.

| Route | Purpose |
|---|---|
| / | Front door: what this is, who is here, how to enter |
| /vision.html | The founding question, principles, honest status of the ambition |
| /ecosystem.html | How the participants relate, what participation does and does not mean |
| /zyphonos.html | Technology and research |
| /pikkaio.html | Brand development and business management |
| /willwired.html | Technology and power access (including EL NINO and TAD) |
| /ebvka.html | Independent artist |
| /work.html | Work and initiatives with honest status labels |
| /participate.html | Seven participation routes |

## Technical

Plain static HTML and one stylesheet. No build step, no framework, no JavaScript, no external fonts, no third-party requests, no analytics, no cookies.

- styles.css — the whole design system (tokens, type, layout, participant accents)

Pages uses the legacy branch publish: branch main, path /. Pushing to main publishes. Keep that in mind: there is no staging.

## Content rules

These are binding for anyone editing this site.

1. No invented clients, testimonials, revenue, results or partnerships.
2. No unapproved prices. Prices are agreed per engagement, in writing.
3. Status labels are factual: ctive, in development, esearch, proposed. Do not upgrade a label for tone.
4. TAD is a **proposed** initiative, not an established or operating foundation.
5. AOSI is a research ambition. Never claim sentience, subjective experience, permanent awareness, autonomous agency or achieved superintelligence.
6. EBVKA is an independent artist. Not owned by PIKKAIO or ZyphonOS.
7. Only verified contact routes may be published. The single public route is the email address on /contact.html.
8. Every participant keeps its own identity, ownership and rights in the copy.

## Accessibility and performance

Semantic landmarks, skip link, visible focus states, prefers-reduced-motion respected, no motion that carries meaning, text contrast checked against the dark surfaces, responsive from 320px up.
